🛡 Security

Every wrong password, lock-out, Admin login, password change and change of rights is written here. Only Admins can see this page. A red bar shows on every page while something new needs your attention.

What protects the logins
• 5 wrong passwords on one login in 15 minutes → that login is locked for 15 minutes (and every try is logged).
• 20 wrong passwords from one internet address in 15 minutes → that address is blocked.
• The internal login address of each person is secret and never sent to the browser.
• Password check for “Approve anyway” is logged too.
If the lock-out hits the real Admin, the other Admin can still log in.
