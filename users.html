Users

One Admin and up to ten more logins. Only the Admin can open this page. Tick approve and/or delete under Edit to make someone a Sub Admin or an approver. Change a login ID, name, password or rights (which apps the person can open) with Edit — the person uses the new details from their next login. After a password change that person is logged out on all their devices within about an hour.

Sub Admin = both ticked. An approver who must not delete (e.g. User 10) = only “approve”. Everyone else takes orders and enters data.
