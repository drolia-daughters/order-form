💾 Backup

All your orders, production, inventory, CRM and approval data lives in the cloud database. It is copied automatically every day at 7:30 PM (India time) and the last 30 days are kept. Only Admins can open this page.

1. Save a copy on a safe place (do this every evening after 7 PM)

Click the button. A file is downloaded. Put that file in your Google Drive (or any place that is not this laptop). If the laptop is stolen or breaks, the file is your full backup.

2. Get your data back

On any laptop: open this site, log in as Admin, open this page, choose the backup file and click Restore. A safety copy of the current data is taken first, so a restore can itself be undone.
